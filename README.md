# fpga_cpu_project

## MAIN GOAL
To build a simplistic CPU using a Nexys A7 FPGA which can execute simplistic code as a proof of concept.

## ADDITIONAL GOALS
1) Attatch additional sensors to the FPGA in the premise of expanding capabilities.
2) Connect the FPGA wirelessly to a phone to display information.

## ROADMAP
- Understand the Foundations of CPU's
- What each function is and how it performs in relation to others
- What pre-requisite files are necessary to create larger core files?

1) Develop an ALU
2) Build a register file
3) Build instruction memory
4) Design a simply instruction format
5) Build a control unit
6) Build the program counter
7) Test and Simulate via Testbenches before implementing
8) Integrate into the physical FPGA board
